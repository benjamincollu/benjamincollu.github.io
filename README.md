# Benjamín Collu - Personal portfolio

A responsive, static personal website for GitHub Pages. Built with HTML, CSS, and a small amount of JavaScript; no build step or external services required.

## Preview locally

Run `python -m http.server 8080 --bind 127.0.0.1` from this folder, then open http://127.0.0.1:8080.

## Editing

- `index.html`: biography, projects, experience, skills, and contact links.
- `style.css`: colors, typography, layout, and mobile breakpoints.
- `script.js`: current copyright year and email-copy interaction.
- `img/`: original portrait and deskhelper photograph.
- `fonts/`: locally hosted Poppins font for the wordmark.

Content refreshed from the supplied LinkedIn export and the original website in September 2026. Decorative robotics and networking illustrations are conceptual graphics, not project screenshots.

Deploy through the repository’s existing GitHub Pages workflow. The existing custom domain configuration is in `CNAME`.
